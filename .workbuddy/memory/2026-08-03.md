## 字体弹窗新增「全部」tab
- 需求：在原「引号内 / 引号外」两 tab 之外新增「全部」，一次选择同时应用到 `--引文字体` 与 `--正文字体`。
- `index.html`：在 `#字体标签引号外` 后追加 `#字体标签全部` 按钮（role=tab, aria-selected=false）。
- `app.js`：
  - `元素` 字典加 `字体标签全部: document.querySelector('#字体标签全部')`。
  - 绑定 `元素.字体标签全部.addEventListener('click', () => 切换字体标签('全部'))`。
  - `渲染字体标签` 改为遍历「引号内/引号外/全部」三个标签，统一处理 `.当前` 与 `aria-selected`。
  - `设置区域字体(区域, 值, 选项={})` 新增 `{ 静默: true }` 选项，跳过中间的 `渲染字体选项 / 安排保存持久化状态`，仅最后一次调用时执行——避免「全部」tab 同步设置两边时出现「引号内已变、引号外未变」的中间渲染态。
  - `处理字体选项点击`：若 `当前字体标签 === '全部'`，先静默设引号内再设引号外；否则走原单区域路径。
  - `重置字体设置`：同样在「全部」下静默清空引号内再清空引号外。
  - `渲染字体选项`：「全部」tab 的 `当前值 = 字体设置.引号内 === 字体设置.引号外 ? 字体设置.引号内 : undefined`——不一致时不预选项，避免误导；预览字体用字体值本身（`null` 时 `inherit` 沿用弹窗当前字体），让用户在该 tab 看到该字体外观。
  - `选项区名` 决定 aria-label：「全部」tab 报「引号内/外统一字体：xxx」。
- 验证：用 Playwright/webkit 跑 12 个端到端断言——三 tab 切换、设置后 CSS 变量同时生效、三 tab 各自正确高亮、分开区域选不同字体后「全部」tab 不预选项、恢复默认同时清空两个变量、先选后恢复仍清空——全部通过。

## 配色重构：「暖纸墨」色系（替代纯黑/灰绿方案）
- 背景：用户反馈上一版「spk 内纯黑 #000 + spk 外灰绿 #4a4f4b」视觉不佳。分析症结：①纯黑在米白纸上 21:1 过于刺眼；②两色不同色系（纯黑 vs 冷灰绿）互不相关；③引文冷蓝底（oklch 238）与暖纸面（色相 85）色温冲突，是最大败笔。
- 新方案（styles.css `:root` 整体换为暖调）：
  - 叙述（spk 外）`--正文字色: #4f4a3d`（暖灰墨，约 8:1）
  - 对话（spk 内）`--引文墨色: #221e16`（浓墨近黑带暖底，约 15:1）——同族墨色深浅两级，非纯黑 vs 死灰
  - `--引文底色` 冷蓝 → 暖沙 `oklch(94.8% 0.018 92)`
  - 纸面/背景/边线/次要墨色同步转暖：`--纸张色 oklch(97.2% 0.008 95)`、`--背景色 #e9e7df`、`--边线色 #dbd7c9`、`--次要墨色 #8a8374`、`--墨色 #2c2924`
  - 辅助色微沉稳：强调色 `#c74e2f`（朱砂）、选中色 `#2f6a5b`（松绿）、高亮色 `#f5d5c2`（暖粉）
- 验证：Playwright WebKit 跳到 8% 对话密集段，注入旧变量对比截图，新暖色系明显更协调，对话/叙述层级仍清晰。截图脚本 /tmp/shot-reader3.js（注入旧变量还原对比法可复用）。
- `index.html`：styles.css?v=20260803-33。
- 备注：弹窗类浅灰底（#f5f7f5、#f8f9f8 等）未转暖，如需彻底统一可再处理。
