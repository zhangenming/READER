## 语音翻页（上一页/下一页）功能
- 目标：监测到「上一页/下一页」语音指令后实时识别并立即同步翻页，无需手动确认。
- 架构（解耦）：`语音订阅.js` 只做识别 → `window.dispatchEvent(new CustomEvent('语音翻页', {detail:{指令}}))`；`app.js` 监听后翻页，再回传 `语音翻页完成`（含当前页/总页）做可视反馈。事件名「语音翻页」「语音翻页完成」是跨模块契约。
- 映射：`上一页` → `翻页整屏(true)`（向后翻/回到上一屏）；`下一页` → `翻页整屏(false)`（向前翻/下一屏）。
- `app.js`：把原嵌套在 `处理键盘按下` 内的 `按整页滚动` 提升为 `绑定事件` 作用域的 `翻页整屏(向上)`，供 Space 与语音共用。
- `语音订阅.js`：识别层 `识别指令`/`判定最终性`/`提取文本`，兼容多种服务器报文（text/transcript/result/alternatives[].text/bestAlternative.text），900ms 冷却防流式转写重复触发。
- 版本号：`app.js?v=20260808-01`、`语音订阅.js?v=20260808-03`。

## wss://localhost:15941 连接失败诊断
- **表象**：WebSocket 反复 `failed`，控制台被「连接断开（服务器未启动？），1s 后重连」刷屏。
- **根因（与表象相反）**：端口上有 node 进程在监听、`curl -k` 能握手成功，**不是服务器没启动**。失败原因是**自签名证书主机名不匹配**：证书 CN = `192.168.0.107`（机器 LAN IP），但客户端连 `wss://localhost:15941`，浏览器主机名校验拒绝。
- **解法**：
  1. 重签证书，把 `localhost`、`127.0.0.1`、`192.168.0.107` 都写进 SAN（最彻底）。
  2. 临时绕开：`http://127.0.0.1:15921/?ws=wss://192.168.0.107:15941`，首次浏览器访问 `https://192.168.0.107:15941/` 信任自签名证书即可。
- **改进**：「服务器未启动？」日志在握手被拒场景下措辞不准，待后续按需优化。
