# 大明王朝1566 · 知识阅读器

> 参照 [baojie/shiji-kb（史记知识库）](https://github.com/baojie/shiji-kb) 的章节页体例，
> 将刘和平《大明王朝1566》（上下卷，江苏人民出版社 2011，约 65 万字正文）转化为
> 可交互的知识阅读页面：实体语法高亮、段落锚点、实体词条索引。

**本地阅读**：`cd docs && python3 -m http.server 8633`，打开 <http://127.0.0.1:8633/>

## 页面结构

```
docs/
  index.html            首页：书籍信息、统计、全书目录
  chapters/00..39.html  40 个章节页（楔子 + 三十九章），正文语法高亮
  entities/             知识索引
    index.html          知识索引总入口：9 类实体卡片（条目数 + 出现次数）
    person.html         人物谱（43 人，含别名、注、标注次数、首末章）
    place.html          地点志
    org.html            机构衙署
    office.html         官职身份
    concept.html        国策思想（改稻为桑）
    tribe.html          族群（倭寇）
    book.html           典籍文书（《大明律》《广陵散》《治安疏》……）
    time.html           时间索引（嘉靖四十年、正月十五、腊月二十九……）
    quantity.html       钱粮数额（四千五百三十六万七千两、五十万匹……）
  original_text/00..39.txt  各章纯文本
  data/entity_stats.json    全部实体统计
chapter_md/             各章实体标注稿（〖@…〗体例，见下）
scripts/
  entities.py           实体词典（含人物别名归一）
  build.py              构建脚本：分章 → 标注 → 生成全部页面
```

## 标注体例

9 类实体，配色沿用 shiji-kb 的阅读器语义（详见 `docs/css/styles.css`）：

| 类别 | 样式 | 示例 | 标注稿符号 |
|------|------|------|-----------|
| 人物 | 棕色下划线 | 嘉靖、海瑞、吕芳 | `〖@肃卿\|高拱〗` |
| 地点 | 金色双下划线 | 玉熙宫、淳安、新安江 | `〖=…〗` |
| 机构 | 紫色实线下划线 | 司礼监、江南织造局、大明 | `〖※…〗` |
| 官职 | 暗红 | 首辅、浙直总督、秉笔太监 | `〖;…〗` |
| 时间 | 青色斜体 | 嘉靖三十九年、正月十五、腊月二十九 | `〖%…〗` |
| 钱粮数额 | 绿色 | 四千五百三十六万七千两 | `〖$…〗` |
| 典籍 | 紫色波浪线 | 《治安疏》《广陵散》 | `〖#…〗` |
| 国策思想 | 红色点线 | 改稻为桑 | `〖^…〗` |
| 族群 | 橄榄绿虚线 | 倭寇 | `〖◆…〗` |

时间与钱粮由正则提取，其余由词典匹配（别名归一：`小阁老/世蕃 → 严世蕃`、
`老祖宗/吕公公 → 吕芳`、`刚峰 → 海瑞` 等，别名表见 `scripts/entities.py`）。

## 功能

- **实体语法高亮**：9 类实体不同样式，点击跳转实体词条页（时间、钱粮亦可点击）
- **知识索引总入口**：`entities/index.html`，9 类实体卡片按出现次数降序排列
- **高亮开关**：章节页右上角 ⚙️，偏好持久化（localStorage）
- **段落编号（Purple Numbers）**：每段带锚点，点击复制链接，可精确引用
- **实体词条页**：别名、注释、标注次数、首现/末现章节

## 重建

修改词典或样式后重新生成：

```bash
python3 scripts/build.py                # 全量构建
python3 scripts/build.py --tagged-only  # 只重生成 chapter_md/ 标注稿
```

原始文本路径由 `DM1566_TXT` 环境变量指定，默认为
`/Users/zem/AI/READER/txt/大明王朝1566（上下卷） (刘和平) (z-library.sk, 1lib.sk, z-lib.sk).txt`。
