# 人名识别与裁决规则（详版）

逐块精读和候选裁决时的依据。原则只有一条：**每个判断都要有原文证据**；规则帮你定位该看什么，不能替你看。

## 1. 收录范围

**收**：

- 完整姓名（含复姓：欧阳、司马、慕容…）、单名直呼（"青梧"作为独立称呼出现时是别名，不是独立人物）。
- 只有姓+称谓、全书从不给真名的：老王、孙先生、王总、李队长、侯掌柜 → 收，canonical 就用这个叫法，identity 注明"真名未出现"。
- 绰号诨号（侯拐子、花和尚）、小名乳名（阿蛮、狗剩）、表字（太岳）、道号法号（玄慈）、化名笔名网名艺名。
- 外族/外国译名（俺答、约翰·史密斯）、有名字的非人类（宠物、坐骑、精怪、AI、器灵）→ 收，`nonhuman: true`。
- 亲属固定叫法当作专有名词用、且指向唯一对象的：海母、海妻、老夫人 → 收，identity 注明与谁的关系。
- 职位/身份作为唯一代称且特指某一人：周镖头、蒋千户、老掌柜 → 收。

**不收**：

- 纯代词：他、她、那人、来者。
- 无特指的泛称：众人、镖师们、一个老者、店家、路人甲——除非全书用某个泛称**固定**指同一个人且无真名（此时按"姓+称谓"处理收进来）。
- 无固定指向的亲属泛称：母亲、师父、兄长。
- 作者、序作者、译者、版权页/参考文献里的人名；书前书后的广告、推荐语里的人名。史书/纪实除外——真实历史人物正常收。

**合称单列**：指代多人的固定搭配——"刘邓"、"林罗"、并称（"青风双侠"）、"父子俩"（有明确指向时）→ 进 `collectives`，绝不并成一个人。

## 2. 别名归并

- 同一人的所有叫法并为一条；`canonical` = 全书最常用、最正式的叫法（通常是最长的全名，但以使用频率为准：若"海瑞"出现 300 次、"海刚峰"出现 5 次，canonical=海瑞）。
- 别名类型清单：全名 / 名（去姓）/ 字号道号法号 / 姓+老小大阿 / 姓+职衔称谓 / 绰号诨号 / 亲称昵称 / 敬称贬称（某公、某老）/ 化名。
- **一个叫法指两个人**（两个"先生"、两个"三哥"）：归到证据多的一方，另一方在 identity/notes 里说明并给出区分上下文。
- **子串别名**（黛玉 ⊂ 林黛玉）正常保留，核验脚本会扣除重叠计数。
- 回忆、梦境、前史里出现的名字照收——只标记 `mentioned_only`，不因"已经死了/还没出场"而丢弃。

## 3. 易漏点清单（逐块精读时逐条自查）

1. 只出现一次的人物（提一次名、递一句话就退场）。
2. 对话中提及的第三者——不在场但被谈论的人。
3. 回忆/插叙/前史/梦境中的人。
4. 书信、日记、碑文、契约、匾额、署名中的人名。
5. 章节标题、卷首语、章末按语里的人名。
6. 绰号先于真名出现（先叫"侯拐子"，几章后才揭示"侯天禄"）——两条候选拼成一人。
7. 外号由事件衍生、无姓氏线索："拐子"、"瘸子"、"秀才"作专称。
8. 转述链里的人名："李四说，张三当年……"——李四、张三都收。
9. 只以"姓+小名"组合出现：王阿贵、陈阿蛮。
10. 少数民族/外国人物的非汉式名字（俺答、也先、瓦剌使者）。
11. 序章/楔子/尾声中的人物（容易被当"正文外"漏掉）。
12. 名字被作者故意写错/别字（角色文化水平设定）——两条写法都记为别名。

## 4. 易误报清单（裁决时逐类排查）

| 类别 | 例 | 判据 |
|---|---|---|
| 地名山水 | 长江、青溪镇、南满、太岳山 | 后接"镇/县/江/山/路"，或上下文是"抵达/位于" |
| 朝代年号 | 大雍、康熙、民国 | 后接"朝/年/年间"，或上下文是纪年 |
| 机构门派 | 翰林院、听雨楼、锦衣卫 | 上下文是"在/去/属于" |
| 部队番号 | 二纵、三师、一野、101 | 数字+编制词 |
| 书名篇名 | 《山河志》、《治安疏》 | 书名号包裹 |
| 成语典故 | 朝秦暮楚、塞翁失马、毛遂自荐 | 秦/塞翁/毛遂未作为独立人物活动 |
| 历史人物作比 | 活菩萨、赛诸葛、再世张良 | 只是比喻，本人未在书中出场 |
| 泛称职务 | 司令、政委、掌柜、地主、东家 | 前面没有姓氏修饰且无特指 |
| 方位动宾 | 向南、向东、南进、北撤 | 方位词+趋向动词 |
| 时间节令 | 清明、立秋、中秋 | 节气/节日词 |
| 普通词 | 马到成功、马上、封锁、结束 | 与上下文连读成普通词组 |

**裁决铁则**：

- 收录需要 ≥1 条原文上下文支持"这是一个人"（在活动、说话、被指认）。
- 只有典故/比喻用法 → 过滤，理由写"仅作比喻"。
- 真实出场哪怕 1 次 → 收为"仅提及/次要人物"。
- 拿不准 → 收进来（宁可多收），理由写"存疑"，进附录。

## 5. 重要性分级口径

- **主角**：视角人物、推动主线；提及通常数百次以上。
- **重要配角**：多章反复出场、有独立情节线；提及数十到数百次。
- **次要人物**：有出场但戏份少；提及 ≥3 次。
- **仅提及**：只被谈到、未直接出场；提及 1—2 次。
- 分级仅供参考（数字只是辅助信号）；史书/纪实类改按阵营/势力分组，分级列可保留可省略。
- nonhuman 条目单独一小节列出，不计入主线分组。

## 6. 英文/翻译作品

- 译名归并靠精读通道（正则对西文基本失效）：Mr. Darcy / 达西 / Fitzwilliam 是一人。
- 姓与全名都是别名：canonical 取全书最常用形式。
- 中文小说夹带西文名（民国背景常见）同样处理。
