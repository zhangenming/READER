## 应过滤（误报）

| 候选 | 理由 |
|---|---|
| 青溪镇 | 地名 |
| 听雨楼 | 楼名/门派 |
| 大雍 | 朝代 |
| 山河志 | 书名（《山河志》） |
| 马到成功 | 成语（马、成功均非人名） |
| 向南 | 方位动宾 |
| 掌柜 | 泛称职务（粮行的掌柜换了两茬，无特指） |
| 众人 | 泛称群像 |

这些词大部分**不会进候选扫描**（不以姓氏开头或次数低于阈值），由逐块精读按易误报清单直接排除；一旦进了扫描并出现在"未覆盖候选"审计里，必须裁决并写理由。样例中实际会出现在审计里的是：`大名`（普通词）、`镇上人都`（句法误切）等扫描杂项。

## 边界提醒

- "镖银没出镇"里的"镇"、"沈"字铜牌的单字"沈"，都不是人名。
- 侯拐子说话引出的"瘦高个"无名无姓 → 不收，但 identity 可在阿蛮/周镖头条目留线索。
- 若候选里冒出"青梧""长风"未并入对应人物，说明归并逻辑有漏。
