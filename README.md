# 原文阅读器

原生 JavaScript 大文本阅读器。正文按实际字宽建立虚拟行索引，并按文字体系与标注边界生成连续片段 DOM，页面只保留当前视口附近的内容。
成对中文引号内的文字会自动以编辑标注样式显示，未配对引号不会影响后续正文。
文本载入时会在句号、问号、感叹号和省略号后自动换行；对话内的句末标点会延后到闭引号后换行。
仅原文自带的单个换行在下一行缩进两格；自动添加的句间换行、空行后的段首和版面自动折行都保持顶格。
正文使用完整纸面宽度，不额外保留左右页边距。

选择正文可同时标记多个关键词，再次选择相同内容可删除对应标记。鼠标悬停在关键词上会显示该处命中的“当前序号/总数”。点击高亮跳到下一处，Shift + 点击跳到上一处，Ctrl + 点击跳到第一处，Ctrl + Shift + 点击跳到最后一处。单按 Alt 可从当前命中继续向下跳转，Shift + Alt 向上跳转，Command + Alt 跳到最后一处，Shift + Command + Alt 跳到第一处。跳转从慢到快持续加速，并让目标命中保持在原高亮所在的屏幕行；当前命中的边框会同步横移到目标位置，落位后边框本身保持不动，另有一簇大小不一的红色圆形碎屑从命中轮廓外随机散开，受重力下坠并缩小淡出。按 Backspace 会一次回到本轮首次跳转前的位置；Space 翻页或手动滚动后，下一次跳转会从新的阅读位置开始记录。

“关键词 N”左侧的“滚动”按钮会显示并保存当前速度；鼠标悬停时自动向下滚动，滚轮向上加速、向下减速，最低可降至 1，鼠标移出按钮后停止。点击按钮可进入或退出全屏模式。按 Ctrl + D（macOS 亦可按 Command + D）也可随时开始或停止自动滚动。

关键词指示器像浏览器查找那样把全文命中位置画成刻度：右列固定显示当前关键词，鼠标悬停在其他关键词的高亮上时，左列同时显示悬停关键词，方便直接对比分布；悬停当前关键词时不重复显示左列，滚动块和阅读进度百分比保持可见；没有对应关键词时各列独立隐藏。刻度用该关键词的深色，并按逐像素命中密度映射深浅：命中密集的段落颜色更深，稀疏处更浅，一眼可见分布重心。刻度与密度按轨道像素反查命中，绘制代价只与轨道高度有关，与命中数量无关；两列共享关键词缓存，滚动时完全不重绘。滚动块和阅读进度百分比平时正常显示，悬停其他关键词时临时隐藏并在移出后恢复；右侧轨道始终支持拖拽、点击、滚轮和键盘操作。

页面右上角的“关键词 N”胶囊可展开关键词管理面板，每行列出色点、关键词和命中数（当前关键词显示“当前项/总数”）。面板顶部可切换列表排序：按命中数量、按首次出现位置或按首字母拼音，排序方式会自动保存。点击关键词本身把它设为当前关键词；“×”删除标记；“≡”打开上下文列表。上下文列表把该关键词的每一处命中以“序号 · 前文 · 命中 · 后文”列为一行，命中列居中对齐便于扫读，点击任意一行跳到正文对应位置；列表按需分批渲染，滚动到底部时继续加载，打开时若当前命中靠前会直接定位到那一行。

按 Space 向下翻动完整一屏，Shift + Space 向上翻动完整一屏；两个方向的翻页距离相同，翻页后首行始终与视口顶部对齐，不会显示半行文字。自动滚动期间按 Space 会立即加速前进当前视口高度的 90%，随后恢复已保存的滚动速度。

按 Ctrl + F（macOS 也可按 Command + F）打开正文查找，输入关键词并回车后跳到第一处，同时高亮全文中的所有匹配项。点击“分析”可统计以输入内容为前缀的词组及其出现数量。

按 Ctrl + A（macOS 也可按 Command + A）打开词频分析。分析仅统计汉字，标点、空白、数字和英文都会分隔前后内容且不计入结果；单字至六字标签分别显示对应词频，二字至六字采用重叠滑动统计，且不显示只出现一次的组合。二字至五字组合如果与相邻更长组合的频次完全相同，表明它从未独立出现，仅保留更长组合。单字同时显示频次倒序和只出现一次两个列表；同频单字按全文首次出现顺序排列。输入框与可编辑区域内仍保留系统全选。

按 Ctrl + S（macOS 也可按 Command + S）打开或关闭字体设置。弹窗顶部有“全部”“引号内（spk 内）”与“引号外（spk 外）”三个标签页，可为全部正文或两个区域分别设置字体与粗细；后一次设置会覆盖所涉及区域，并自动保存。弹窗为普通浮层（非 dialog 元素），可通过右上角 ×、底部“关闭”按钮、点按遮罩层、按 Esc 或再次按 Ctrl + S 关闭。

阅读位置、已标记关键词、面板排序方式及当前命中会自动保存在浏览器中，刷新页面后继续恢复。

## 运行

```bash
python3 -m http.server 15921 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:15921`。
