# 原文阅读器

原生 JavaScript 大文本阅读器。正文按实际字宽建立虚拟行索引，并按文字体系与标注边界生成连续片段 DOM，页面只保留当前视口附近的内容。
成对中文引号内的文字会自动以编辑标注样式显示，未配对引号不会影响后续正文。
文本载入时会在句号、问号、感叹号和省略号后自动换行；对话内的句末标点会延后到闭引号后换行。
仅原文自带的单个换行在下一行缩进两格；自动添加的句间换行、空行后的段首和版面自动折行都保持顶格。
正文使用完整纸面宽度，不额外保留左右页边距。

选择正文可同时标记多个关键词，再次选择相同内容可删除对应标记。鼠标悬停在关键词上会显示该处命中的“当前序号/总数”。点击高亮跳到下一处，Shift + 点击跳到上一处，Ctrl + 点击跳到第一处，Ctrl + Shift + 点击跳到最后一处。单按 Alt 可从当前命中继续向下跳转，Shift + Alt 向上跳转，Command + Alt 跳到最后一处，Shift + Command + Alt 跳到第一处。跳转从慢到快持续加速，并让目标命中保持在原高亮所在的屏幕行；当前命中的边框会同步横移到目标位置，落位后边框本身保持不动，另有一簇大小不一的红色圆形碎屑从命中轮廓外随机散开，受重力下坠并缩小淡出。按 Backspace 会一次回到本轮首次跳转前的位置；Space 翻页或手动滚动后，下一次跳转会从新的阅读位置开始记录。

“关键词 N”左侧的“滚动”按钮用于自动向下滚动；滚动期间，鼠标滚轮向下加速、向上减速，移动鼠标或再次点击按钮会停止。

关键词指示器与滚动条共用同宽轨道，像浏览器查找那样把全文命中位置画成刻度。同一时刻只画一个关键词：鼠标悬停在某处高亮时画该关键词，否则画当前关键词；没有当前关键词也没有悬停时隐藏刻度。刻度用该关键词的深色。刻度按轨道像素反查命中，绘制代价只与轨道高度有关，与命中数量无关；刻度按关键词缓存，悬停切换只重新合成底图，滚动时完全不重绘。自定义滚动块显示 0–100 的阅读进度，并支持拖拽、点击轨道、滚轮和键盘操作。

按 Space 向下翻动完整一屏，Shift + Space 向上翻动完整一屏；两个方向的翻页距离相同，翻页后首行始终与视口顶部对齐，不会显示半行文字。

按 Ctrl + F（macOS 也可按 Command + F）打开正文查找，输入关键词并回车后跳到第一处，同时高亮全文中的所有匹配项。点击“分析”可统计以输入内容为前缀的词组及其出现数量。

阅读位置、已标记关键词及当前命中会自动保存在浏览器中，刷新页面后继续恢复。

## 运行

```bash
python3 -m http.server 15921 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:15921`。
