# 原文阅读器

原生 JavaScript 大文本阅读器。正文按实际字宽建立虚拟行索引，并按文字体系与标注边界生成连续片段 DOM，页面只保留当前视口附近的内容。
成对中文引号或书名号内的文字会自动以编辑标注样式显示，未配对符号不会影响后续正文。原文漏了下引号时，误判最多波及它所在的那一个自然段；下一段以同型开引号续起时按多段引文照常连成一条。
文本载入时会在句号、问号、感叹号和省略号后自动换行；对话内的句末标点会延后到闭引号后换行。
正文按原文段落交替显示灰蓝与淡珊瑚底色；段内的句子换行和屏幕折行均保持为一个连续色块。
正文使用完整纸面宽度，不额外保留左右页边距。

选择正文可同时标记多个关键词，再次选择相同内容可删除对应标记。拖选过程中按下 Ctrl + C（macOS 同样认 Command + C，右键菜单复制也算）就把这次选区当作复制用途，松手时不再增删关键词，原生复制照常写入剪贴板；没有选中文字的复制键不影响下一次拖选建词。鼠标悬停在关键词上会显示该处命中的“当前序号/总数”。点击高亮跳到下一处，Shift + 点击跳到上一处，Ctrl + 点击跳到第一处，Ctrl + Shift + 点击跳到最后一处。单按 Alt 可从当前命中继续向下跳转，Shift + Alt 向上跳转，Command + Alt 跳到最后一处，Shift + Command + Alt 跳到第一处。跳转从慢到快持续加速，并让目标命中保持在原高亮所在的屏幕行；当前命中的边框会同步横移到目标位置，落位后边框本身保持不动，另有一簇大小不一的红色圆形碎屑从命中轮廓外随机散开，受重力下坠并缩小淡出。按 Backspace 会一次回到本轮首次跳转前的位置；Space 翻页或手动滚动后，下一次跳转会从新的阅读位置开始记录。跳转触发键以 Meta/OS 键判定（见 app.js 键盘处理注释），在 Ctrl↔Win 键位对调的环境中，物理 Ctrl 会被系统作为 Meta/OS 送达页面，因此按物理 Ctrl 可正常触发；物理 Win 键不触发。

按住某个高亮词不放约半秒（鼠标或手指长按同理），打开该词的查找窗口，自动填入关键词，上下文与搭配分析直接停在按住的那一处命中；正文保持原位不滚动，关闭窗口也不会回跳。按住期间一旦越过拖拽死区就交还给拖拽手势，短按仍是原来的单击前进，松手补发的点击也不会让正文再前进一格或误关窗口。

“关键词 N”左侧的“滚动”按钮会显示并保存基础速度，自动滚动时同时显示按内容密度调整后的实际速度；预计剩余阅读时长显示在右下角当前时间上方。悬停按钮不再启动滚动，该按钮只负责显示速度与点击切换全屏。自动滚动改由键盘启动：按 Ctrl + D（macOS 亦可按 Command + D）随时开始或停止，按 → 或双击 Shift 也可开始；Tab 键聚焦到按钮时启动、失去焦点时停止，鼠标点击按钮的聚焦不算。滚动中滚轮向上加速、向下减速，最低可降至 1；移动鼠标会立即停止自动滚动，光标随之恢复。按住 Z 会以基础速度的 2 倍向下滚动，按住 X 会以同样速度向上滚动，松开即停。

右下角的“内容”按钮会读取 `./txt/` 目录中的全部 `.txt` 文件，弹窗是一张表格：一行一本书，书名列吃剩余宽度（超长省略号收尾、悬停看全名），右边依次是「万字 / 已阅读 / 进度 / 状态」四个量各占一列，逐列竖着对齐、数字右缘压表头右缘。点列头按该列排序，再点反向（书名按拼音、其余数值首点为从大到小）；还没统计出字数、没有阅读记录的书钉在尾部，不随方向跳到最前。没读过、没进度都留白而不是写 0，「状态」那一列说清楚它是加载、继续还是当前在读。点击任意一行（或聚焦后按 Enter / 空格）切换正文。回归见 `node tmp/verify-内容选择表格.mjs`。

关键词指示器像浏览器查找那样把全文命中位置画成刻度：页面左缘只剩一条白轴、一列刻度，选中关键词铺满整列，进度数字立在同一个位置；原先的章节刻度与它那一列一起撤下，章节只在章节目录里看。鼠标悬停在其他关键词的高亮上时，整列换成那个词的刻度与配色——一列一次只显一个词，不再并排两列供直接对比；悬停当前关键词时不换。白轴宽度不是定值：它吃掉的是「视口宽 - 行首留白」除不尽正文字号的那点余量，于是正文每行正好是整数个字、末字永远贴着视口右缘收尾（1440px 视口、30px 字号下为 47 字/行、白轴 30px）；字号或窗口一变，白轴就在 0 到一字号之间跟着浮动。刻度用该关键词的深色，并按逐像素命中密度映射深浅：命中密集的段落颜色更深，稀疏处更浅，一眼可见分布重心。刻度与密度按滚动块中心的可用轨道区间反查命中，与阅读进度数字使用同一坐标，绘制代价只与轨道高度有关，与命中数量无关；切换关键词共享同一份刻度缓存，滚动时完全不重绘；没有关键词时整列隐藏。进度数字只有整数（`29`）、不带百分号，单位靠悬停提示与 aria 说明，数字立着逐行堆叠而不是躺倒旋转。位置由两样东西标出：一条 1px 朱砂红横线贯穿数字列、压在数字下方，右端接一枚朱砂红三角朝正文（右）指；指针随滚动块上下移动，不浮在正文上压字。右侧轨道（20px）不再画任何刻度，只保留滚动条本体与一枚指针——同样的 1px 横线贯穿轨道、三角朝正文（左）指；两枚指针由同一个夹取后的中心驱动，读数盒子按自身内容定高并整体夹在视口内，书首书尾宁可让指针偏离滚动块中心半枚读数，也不裁掉数字，左右两枚因此永远不会错开。右侧轨道始终支持拖拽、点击、滚轮和键盘操作。

页面右上角的“关键词 N”胶囊可展开关键词管理面板，每行列出色点、关键词和命中数（当前关键词显示“当前项/总数”）。面板顶部可切换列表排序：按命中数量、按首次出现位置或按首字母拼音，排序方式会自动保存。点击关键词本身把它设为当前关键词；“×”删除标记；“≡”打开统一的查找窗口，自动填入关键词并定位当前命中。上下文列表以“序号 · 前文 · 命中 · 后文”展示结果，命中列对齐，点击任意一行进入正文。列表从当前命中所在批开始渲染，向上或向下滚动按需补充，避免一次创建大量结果。

按 Space 或 Enter 向下翻动完整一屏，Shift + Space 或 Shift + Enter 向上翻动完整一屏；翻页按视口内的完整行数移动，底部未显示完整的行不会被跳过，两个方向的翻页距离相同，翻页后首行始终与视口顶部对齐。自动滚动期间按 Space / Enter 或说“快”，会将滚动速度提高 10%，立即加速前进当前视口高度的 70%，随后恢复调整后的速度；按 Shift + Space / Shift + Enter 或说“慢”，会将速度降低 10%，显示衔接线并向上滑动半页，暂停一秒后继续滚动。

按 Ctrl + F（macOS 也可按 Command + F）打开正文查找，默认填入当前选中文字；没有文本选区时使用当前关键词，两者都没有则保留上次查询。仅打开查找窗口不会移动正文，仍会显示匹配结果；输入查询或主动导航时才定位正文。查找窗口左侧是关键词、上一个 / 下一个和命中计数，右侧同时显示上下文和搭配分析，窗口尽量占满可用高度。共用同一组匹配结果，包括排除前缀筛选（例如 `!他的` 查找前面不是“他”的“的”）。搭配分析列出关键词前后的高频接续；若某个接续每一次出现再往前或往后都是同一个汉字，则自动并入更完整的搭配，避免显示从未独立出现的残缺组合。点击某条搭配会把查找改为对应的完整关键词，例如点「秉笔」即查找「秉笔太监」。上一个 / 下一个或输入框内的方向键用于循环预览；Enter 立即查询，已有结果时前进到下一处。点击结果关闭窗口并留在该处，支持 Backspace 回跳；Esc、× 或点击遮罩取消预览，返回原阅读位置。查找临时高亮不会加入持久关键词列表。除快捷键外，关键词面板的“≡”与正文长按高亮词都会带着对应关键词进入同一窗口：面板入口会把那一处命中定位到视口中央，长按入口只展开结果、不挪动正文。

按 Ctrl + A（macOS 也可按 Command + A）打开词频分析。分析仅统计汉字，标点、空白、数字和英文都会分隔前后内容且不计入结果；标签是「字频对照」加二字至六字，单字标签已去掉——单字的频次、名次和出现次数都被「字频对照」覆盖，再留一个纯频次列表只是重复。二字至六字采用重叠滑动统计，且不显示只出现一次的组合；二字至五字组合如果与相邻更长组合的频次完全相同，表明它从未独立出现，仅保留更长组合。同频单字按全文首次出现顺序排列。输入框与可编辑区域内仍保留系统全选。

标签栏最前面的「字频对照」把本书每个汉字和现代字频并排，五列：汉字 | 序号 | 知乎万分之 | 序号 | 本书万分之（次数）。名次排在数值前面，先扫第几名、再看每万次出现几次；本书出现次数并进万分之后面的括号里（原来单列「字符个数」占一整列，而万分之脱离真实次数看单个数字没有意义），括号沿用差异榜同一份 `格式化次数`（过万写「1.2万」），列宽固定不换行——虚拟列表按固定行高算窗口，换行会让可见行数与渲染行数对不上。万分之是每 1 万个汉字里出现多少次（≥10 向下取整，所以现代语料里“的”是 403；不足 10 保留 3 位有效数字，低频字不会被抹成 0），序号是该字在对应语料里的名次（知乎那一组按 7,422 字的现代字频表排名，本书一组按它在书里的频次排名）。四列（两组名次 + 两组万分之）都可以点表头排序：点一次给该列的自然序（数值列从大到小、序号列从第 1 名开始），再点反向，表头带 ↓/↑ 标记（箭头放在标签左侧，否则会把表头文字推离数字的右边缘），摘要同步写明“按哪列什么序”；本书用到但现代表里没有的字（扩展区、繁体、生僻字）知乎两格显示「—」，无论升降序都恒定排在最后，不静默丢行。默认按本书万分之降序，摘要同时给出“本书 N 字中 M 字有对照值”，两列可各自对账（本书列合计 10000 万分之）。数据入库为 `js/知乎字频.js`（纯数据模块，无依赖），源表留档 `tmp/字频-知乎6亿字.csv`，改数据后重跑 `node tmp/生成-知乎字频.mjs`；字频表来自 forfudan/chinese-characters-frequency，Apache-2.0。

每个视图（字频对照、二至六字）都走同一套虚拟列表 `js/虚拟列表.js`：固定行高 + 视口窗口切片 + 上下各 8 行缓冲，用两条占位行把总高撑出来，所以几万条也只挂二十几行 DOM，直接滚就行，没有翻页条。列表容器可聚焦（Tab 到位后用方向键 / 空格滚动）。

对照视图右侧还挂着一个**独立**的差异榜模块（`js/字频差异.js`）：三列各 30 行——「偏本书 ×30」（倍数 ×，本书用得远比现代多）、「偏知乎 ÷30」（倍数 ÷，本书用得远比现代少）、「差异最小 30」（倍数最贴近 1），一次渲染完，不进虚拟列表、不接主表的滚动，三列各自有自己的滚动条，主表排序或滚动都不影响它们，彼此也互不影响（对照视图下弹窗加宽到 1260px 才放得下，回归里断言主表五列不被挤成横向滚动、行高统一 34px 不换行）。差异口径是「本书万分之 ÷ 知乎万分之」的倍数，按 |log₂| 排：不用绝对差是因为绝对差的最大端永远是「的了是一」这些高频虚词、最小端永远是两边都不出现的生僻字，两头都没有信息量；× 和 ÷ 分列而不是混在一列，是因为混着排会把「这本书回避的现代常用字」和「这本书独有的字」互相挤掉，两端各看各的才看得出取向。本书出现过的每个字都参与，不设次数门槛；但知乎那一侧必须有数——计 0 次或压根未收录的字没有分母，属于「没有数据」而不是「差异极大」，一律不入榜，说明行会写明「本书 N 字中 M 字入榜，知乎计 0 次或未收录的 K 字无数据、不入榜」，M+K=N 可对账。（早先把这类字按语料 1 次折算，结果它们以 ×6,117 顶满榜首，是错的。）每列给「字 / 知乎 / 本书 / 倍数」，知乎一栏与主表同口径（未收录显示「—」、表内计 0 显示「0」）；倍数接近 1 时保留两位小数、过万改用「万」，免得「差异最小」整榜印成同一个 ×1。

模块顶部另有一行**全书汇总**（`汇总偏度`，对全部入榜字算、不是那 90 行榜单的平均），通用形式是 |log₂ 倍数| 按本书字数加权的几何平均 `2 ^ (Σ 次数 × |log₂ 倍数| ÷ 计入字数)`，读作"随机翻开本书一个汉字，它的常见程度平均偏离知乎 N 倍"。加权和取对数两个约束都省不掉：直接对倍数做算术平均会被长尾炸掉（金瓶梅 27、成吉思汗 68，全是 ×4000 那档生僻字顶起来的），而且 ×2 与 ÷2 在它里面不等权（平均成 1.25 而不是 1，偏本书和偏知乎两个方向互相污染）；按字种等权（每个字一票）会随书的长度单调上涨（金瓶梅前 5 千字 3.97 → 全书 4.63），量的是"字表攒了多长"而不是这本书的用语风格。只有按次数加权在 2 万字后就稳住，厚薄差十倍的书可以直接横比。

**这个量必须拆成两段报，合成一个数会骗人**：语域偏离只取知乎表前 100 常用字（的、一、是、不、我……几乎全是虚词，约占全书 25%~49% 篇幅），量的是这本书的中文离当代白话有多远；主题偏离取其余 7,322 字，量的是题材用字有多专。门槛取名次而不是万分之数值，因为名次直接对应"前 100 常用字"这个说法，换语料表也不用重算门限。库内实测（语域 / 主题 / 合计）：未来简史 ×1.36 / ×1.91 / ×1.64、赢 ×1.38 / ×1.96 / ×1.66、思考快与慢 ×1.41 / ×2.16 / ×1.77、笑傲江湖 ×1.58 / ×3.94 / ×2.77、骆驼祥子 ×1.68 / ×2.90 / ×2.21、**债务危机 ×1.69 / ×4.31 / ×3.22**、金瓶梅 ×1.91 / ×4.61 / ×3.35、成吉思汗 ×2.69 / ×9.61 / ×7.00。合起来一个数会把 债务危机（×3.22）排到 笑傲江湖（×2.77）前面，读起来像"这本财经书比金庸更不现代"——那是误读：它的语域段和 骆驼祥子 一个水平（×1.69 vs ×1.68），高分全在主题段的 债 ×182、胀 ×155、贷 ×83、储 ×73、币 ×62；而 笑傲江湖 的偏离结构完全不同，语域段里在动的是虚词（的 ÷2.42、之 ×3.30、得 ×1.84 的半文言），主题段靠人名（令狐冲：狐 ×305、令 ×68、冲 ×40）。两段之外还报一个**与知乎字频重合** = Σ min(本书万分之, 知乎万分之) ÷ 10000，即 1 − 全变差距离，永远落在 0~100%、天然抗离群值；两侧都是真分布（表合计 10000、本书合计 10000），本书没用过的字 min 为 0、表里没有的字也是 0，只需遍历本书字种，不用补集也不用重归一。三个偏离全部复用榜单同一个 `格式化倍数`，所以顶上写的 ×1.8 和列里的 ×1.8 是同一件事。知乎无分母的字同榜单一样不入平均，合计占全书多少篇幅会写进说明行——不足 0.01% 时写「<0.01%」、真为 0 时那段整个不出现（赢 就是 0 字不入榜）；重合度按 min(p, 0) 计不受影响。口径对比脚本 `node tmp/分析-字频偏度.mjs`（五种候选算法在全部书上横向跑），端到端回归 `node tmp/verify-字频汇总.mjs`。

按 Ctrl + S（macOS 也可按 Command + S）打开或关闭字体设置。弹窗顶部有“全部”“正文”“spk”“关键词”与“背景”五个标签页，可为全部正文或两个区域分别设置字体与粗细；“全部”还可独立设置内置字词颜色，统一控制数字、人称代词、关系字与内置连词的字色；“正文”标签页可设置奇偶段落的整行底色。也可单独设置关键词颜色与粗细以及同时控制页面背景与纸面的背景色；关键词粗细支持点击或在按钮上滚动滚轮逐档循环调整。spk 按全文出现顺序交替使用奇数、偶数背景色，不受所在段落或虚拟滚动范围影响；“spk”标签页可分别配置两种颜色，也可关闭背景色。后一次设置会覆盖所涉及区域并自动保存。弹窗为普通浮层（非 dialog 元素），可通过右上角 ×、底部“关闭”按钮、点按遮罩层、按 Esc 或再次按 Ctrl + S 关闭。

每篇文本分别保存自己的完整阅读状态，包括阅读位置、自动滚动速度、字号、行距、字体、字体粗细、内置字词颜色、关键词颜色与粗细、奇偶行颜色、背景色（页面背景与纸面）、spk 奇偶背景色、关键词、当前命中及关键词面板设置。切换文本或刷新页面后会恢复对应文本的状态，彼此不会覆盖；首次打开尚无状态的新书时，字号、行距、字体、内置字词颜色、关键词样式、奇偶行颜色、背景色、spk 奇偶背景色、自动滚动速度等公共设置默认继承上一本书，阅读位置和关键词保持为空。

每本书的身份判据是**文件本身的内容指纹**（对解码后的原文算 32 位 FNV-1a，实测 2.9M 字的书 1~2ms），不是管道跑完之后的正文长度——正文长度只决定阅读偏移能不能原样落回去。指纹一致而长度变了（管道规则升级、句子整理改了换行），关键词按文本在当前正文里重扫命中后照常恢复，阅读位置按长度比例折算回近似位置；指纹不同（文件真的换了）同样不丢关键词，只折算位置。两种情况都在控制台留一条「持久化指纹与当前内容不一致」的对账日志，落盘时指纹自愈。加指纹之前的旧记录没有指纹，先按长度认同一份内容并标成「无指纹」，下一次保存补上。查找历史按文本保留，只是漂移后旧命中数不再可信，那一格显示「—」，重新查找即回填。

本地阅读状态不是有效 JSON、或数据库外层结构损坏时，页面会先使用空状态继续打开；首次重建前会把本次损坏的原始值写入独立备份，备份失败则保留原值并取消覆盖。备份只保留最近一次损坏快照。

## 章节目录

右下角“内容”旁的“目录”按钮显示识别出的目录项数量。打开后显示当前章节和本章进度，点击标题跳到正文对应位置；搜索框按标题过滤，“当前章节”清除搜索并定位到正在阅读的目录项。目录超过 100 项时分页显示，重新打开会直接显示当前章节所在页。Esc、右上角 × 或点击遮罩关闭目录。

- 自动识别原文中独立成行的“第十二章”“第1回”“卷一”“第一部分”等标题，以及序章、楔子、尾声等序跋和 `Chapter 1` 标题。章号后有标题时需用空白、冒号或破折号等分隔；不把普通正文、裸数字或“一、…”清单当作章节。连续的英文数字标题与下一行中文标题配对时也可识别。
- 遇到明确的“目录”标记时，排除书前、书后的重复目录条目，并兼容页码后缀及分卷重号。采用保守规则，不保证识别所有自定义标题格式；没有识别结果时会显示说明，不影响正文阅读。
- 按原始行识别标题，再将字符位置映射到自动分句后的正文；字号、字体、行距和窗口宽度变化后仍按字符位置跳转。切换文本会重新建立对应目录，阅读位置继续使用现有的每篇文本独立保存机制。
- 打开目录会停止自动滚动和按键滚动；目录内的键盘操作不会触发正文翻页。进度按视口顶部的文本位置估算，到达书末时显示最后一章 100%。目录列表只渲染当前页，不为全文创建额外正文节点。
- 识别到章节后，右侧滚动条轨道上会以灰色横线标出每个章节的起始位置（与阅读进度箭头共用同一坐标），一眼看清全书的章节分布与长短。
- 正文里的章节标题行可直接点击跳章：单击跳到下一章标题，Shift + 单击 跳到上一章，落点与目录点击一致（标题顶到视口上沿），并停住自动滚动。悬停时整条标题转朱砂红并压出一条同色下划线、行尾浮出「下一章 →」提示；命中词不参与变色（它自带黑底白字），长标题折出的每一行都算标题行（整段可点，但不浮出行尾提示，免得压在字上）。标题行内的高亮词仍以关键词导航优先；双击标题行保持原来的「选中并复制整行」，不会抢跳章；已在首章之前或末章时原地不动。
- 悬停章节标题行时，页面左缘那一列（平时给关键词刻度独占）整列换成全书签章地图：每章一枚 1px 发丝线，被悬停的那章用与标题变色同一支朱砂红加粗标出，与阅读进度共用同一套轨道坐标，一眼看出各章的疏密与下一章有多远。移开即收回，正指着标题行里的命中词时让给关键词刻度（与点击同一条优先级）。

## 阅读统计

右下角「统计」按钮打开阅读统计弹窗，弹窗为固定黑白主题，不受正文自定义背景色影响。摘要分别展示今日与累计的滚动时长、前台停留时长以及本书进度。书籍明细同时列出「滚动」「前台停留」「进度」三列，按书给累计值，不可点选；原先那块「每日阅读 · 某本书」的按日明细已撤下（每日的滚动与激活改由底部时间轴按天呈现）。当前书进度按滚动位置计算，其余书籍按上次保存的文本位置估算。未满 1 分钟显示「不足 1 分钟」，无记录显示 0 分钟。

前台停留以浏览器页面可见性为准：书籍载入后，手动阅读、自动滚动、打开弹窗均计时；切换到其他标签页或最小化导致页面隐藏时暂停，返回后继续。仅窗口失焦但页面仍可见时继续计时。两类时长独立统计，不能相加当作总阅读时间。停留时间按书籍及本地日期保存，跨午夜分日记账；每 30 秒及隐藏、离开页面时保存，换书不会混入另一本书。前台停留从升级后开始记录，不从历史滚动时长推算；旧版未按日记账的滚动累计仍只显示在书籍明细中。同一处会话开关还会记一条「页面激活时段」（几点到几点开着页面），见下。

时间轴在弹窗底部按「一天一行」渲染，叠两类时段：浅色底带是页面激活（与前台停留同口径，有书且页面可见），深色块是持续滚动，滚动块必然落在激活带里，一眼能看出「页面开着」和「真的在滚」的差别。所有行共用同一条轴，轴的范围覆盖两类数据的最早起点到最晚终点，不画满 24 小时；后面出现更早或更晚的时间段时轴自动外扩。自动滚动和按住按键滚动是同一个功能的两种触发方式，因此滚动只记一种色块，不区分怎么触发的。色块悬停显示起止时刻与时长，行尾分两行给出滚动段数与合计、激活合计。跨午夜分日记账，页面隐藏时就地封口；滚动段间隔不超过 60 秒即合并（中途从自动切到按键也接成一段），激活段只合并 10 秒内的抖动（切走再回来算真离开），每天最多 240 段、只保留最近 365 天。两类时段都从升级后开始记录，不从历史时长推算。打开弹窗时，正在进行、还没封口的那一段也会按当前时刻画到轴上（与落盘快照同一算法），所以「激活」和上表「前台停留」算到同一秒，不会因为「此刻这段还在读」而少画一截。

上方「滚动」列与这条轴吃同一对起止时刻：滚动会话开始、结束时按墙钟时间入账，自动滚动与按住方向键都算。旧口径逐帧累加且每帧最多记 50ms，掉帧的时间被吞、按键滚动更是一分钟都不记，于是「读了多久」比轴上同一段滚动短一截。改按起止入账后两行仍可能不等，只剩两种来由：轴把间隔不超过 60 秒的两段并成一段、中间的空闲一并计入，以及轴按全部书籍合并而上表按书拆分。这两条写在各自列头的悬停里。第三种来由已修掉：时长就地结转算到眼前，而轴一度只画已封口的段，当前这段没结束就不上轴。

## 运行

```bash
npm start
```

（等价于 `node server.mjs`，默认端口 15921。）

服务对所有资源发送 `Cache-Control: no-cache`：浏览器每次刷新都会回源校验，文件没变走 304，改完代码**普通刷新即可看到最新版**，无需强制刷新，也无需在 `index.html` 里维护 `?v=` 版本号。（若仍用 `python3 -m http.server` 起服务，它不发送缓存头，浏览器只能启发式缓存 JS/CSS，普通刷新经常拿到旧代码，需要强制刷新。）

目录请求（如 `./txt/`）在没有 `index.html` 时会返回 HTML 目录列表，右下角「阅读内容」弹窗就是靠解析这个列表得到文本清单的；新增 txt 无需改代码，放进入目录即可。回归可用 `node tmp/verify-txt-directory-listing.mjs`（自带无头 Chrome，`SITE_PORT` 指定服务端口）。

本机浏览器打开 `http://localhost:15921`；同一局域网内可使用本机的局域网 IP 访问，例如 `http://192.168.0.101:15921`。
