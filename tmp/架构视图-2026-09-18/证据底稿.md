## 自动滚动运行时链路（用于 flow 视图）

rAF 主循环：`js/自动滚动.js:522` `执行自动滚动(当前时间)`，句柄 `自动滚动状态.帧`，首帧 `:275`、自续 `:621`、取消 `:629`。
存在**第二条并行 rAF**：`执行按键滚动`，`:297` 起、`:332` 自续、`:340` 取消。

一帧内数据流（已核实行号）：

1. `:529` 取 `经过毫秒` 并夹到 50ms 上限 → `:530` 指数缓动比例
2. `:551` `浮点位置 += 当前速度 * 经过毫秒 / 1000`（px/s → px）
3. `:583` 写 `元素.滚动容器.scrollTop`（整数）
4. `:613-615` 回读整数 `scrollTop`，把 `小数位移` 写成 `可见内容.style.transform` —— **sub-pixel 补偿，双写**
5. `:584` 50ms 节拍门（`js/常量.js:45`）→ `:599` `渲染可见行(false, 容器高度)`、`:602-609` 速度/剩余时间文本、`:608-609` 已滚动时间与今日总时长
6. 每帧 `:598` `更新滚动块(度量)`、`:616` `更新滚动块位置(度量, 浮点位置)` → `js/滚动条.js:162-167,195-226`

关键事实：
- **热路径不读布局**：起点由 `scrollTop` 初始化（`:257`）、`最大滚动位置` 一次性缓存（`:270`），积分量是自定义 `浮点位置`。
- **`js/调度.js` 不在自动滚动链路里**：`js/自动滚动.js:1-31` 的 import 列表无 `调度.js`，全文仅 `:281` 一处字符串 `'requestAnimationFrame'`。`调度.js` 只服务索引重建（`js/排版引擎.js:230-248,448`），入口 `app.js:238` / `js/字体设置.js:50`。置信度 high。
- **滚动事件不驱动渲染**：`app.js:704` 的 scroll-rAF 在 `:700,:706` 于自动滚动期间短路。
- 前瞻窗口：`:488-520`，`:494` 窗口下移 0.3 视口（`js/常量.js:64`），`:503-506` 调 `js/排版引擎.js:478` `二分句段起点` + 前缀和，`:512-518` 因子夹取与强度 0.7 幂映射。
- 两个速度量：基准 `js/状态.js:156` `状态.自动滚动速度` vs 帧内 `js/自动滚动.js:256` `当前速度`；另有 `:263,:594` `密度目标速度`。

启动路径：`app.js:418-419`（mouseenter/focus）→ `js/自动滚动.js:233` → `:239/248/249` 抢占取消 → `:251-274` 建状态 → `:275` 首帧 → `:550-551` → `:583` 首次位移。
